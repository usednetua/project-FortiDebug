## 5. Як користуватись індексом

1. **Новий документ у `doc/`** → додати рядок у відповідну таблицю (категорія) + оновити дату «Останнє оновлення».
2. **Зміна статусу плану** (Todo → Done тощо) → оновити колонку «Статус» тут і в таблиці всередині самого плану.
3. **Видалення документа** → прибрати рядок з INDEX у тому ж коміті.
4. **README** у корені репо може посилатись на цей INDEX як єдину точку входу в документацію.
