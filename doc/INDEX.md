## 5. Як користуватись індексом

1. Новий документ у `doc/` → рядок у таблиці + дата.  
2. Зміна статусу плану → INDEX + таблиця всередині плану.  
3. Видалення → прибрати з INDEX у тому ж коміті.  
4. README → посилання на INDEX.
